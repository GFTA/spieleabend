Mehrspieler

Mehrspieler läuft über eine Party: Der Host wählt das Spiel, alle landen im selben Raum.

Zur Party

Für „Mehrspieler“ muss das Spiel auf einem Server laufen, zum Beispiel auf deinem eigenen Server. Öffne dann dessen Adresse, etwa http://192.168.1.50:8086. Hier geht nur „Einzelspieler“.
