Spieleabend

Jeder mit dem eigenen Handy, oder allein gegen den Computer. Such dir ein Spiel aus.

Du

Name, Avatar und Design nimmst du in jedes Spiel mit, das du von hier aus öffnest.

Raum erstellen

Einer öffnet ein Spiel, wählt „Mehrspieler“ und erstellt einen Raum.

Beitreten

Die anderen scannen den QR-Code im Spiel oder tippen den Raum-Code hier beim Spiel ein.

Allein?

Oben „Einzelspieler“ wählen: dann geht es gegen den Computer, ohne Raum und ohne Code.

Läuft auf dem Mini-PC zu Hause · Code auf github.com/GFTA/spieleabend
